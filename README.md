# ⚽ Goal Rush 2026

A fun penalty shootout football game built with HTML, CSS, and JavaScript.

## 🎮 How to Play
1. Click the "PENALTY SHOOTOUT" button
2. Aim and shoot to score goals
3. Stop the goalkeeper from saving
